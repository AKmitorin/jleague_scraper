# jleague\_scraper

[Jリーグ公式サイト](https://www.jleague.jp)から選手の個人スタッツを取得し、Excelで開きやすい形式のCSVに出力するPythonツールです。  
チーム単位だけでなく、リーグ全体の全選手データの取得にも対応しています。

## まずは最短で動かす（Windows向け）

1. Pythonをインストール（未導入の場合）  
2. 任意のフォルダで以下を1行ずつ実行

```shell
git clone https://github.com/AKmitorin/jleague_scraper
cd jleague_scraper
pip install -r requirements.txt
py main.py
```

引数なしで実行すると、対話式ウィザードが起動します。質問に答えるだけでOKです。
Mac・Linuxを使用している方は、 `py` コマンドを `python3` に置き換えてください。以下で紹介する使い方についても同様です。

Windowsではエクスプローラー上で `run_windows.bat` をダブルクリックしても起動できます。

## 特徴

- **全82項目に対応**  
  出場試合数、得点、アシストといった基本情報から、ゴール期待値、パス成功率、走行距離、スプリント回数などの詳細データまで取得できます。
- **リーグ全体データの完全取得**  
  `--team all` 実行時は各チームの個別ページを巡回するため、ランキング順位に関係なく選手一覧を起点に取得します。
- **現行一覧にない選手の照合**
  過去シーズンの選手IDを現行J1/J2/J3の一覧と照合します。現行一覧にない選手は個人ページへのアクセスを省略し、ランキングや補完表で確認できる値だけを使います。
- **日本語ヘッダー付きCSV**  
  出力されるCSVは日本語項目名（単位付き）なので、そのまま分析に使えます。
- **Excel対応**  
  BOM付きUTF-8で保存されるため、ExcelやGoogleスプレッドシートで文字化けせずに開けます。
- **柔軟な指定**  
  2018〜2026-27シーズン、カテゴリ（J1/J2/J3）を指定できます。2018年はランキングのみ、2019年以降は個人ページとチーム別ランキングを使います。

## 使い方

### シーズン別スタッツの取得

Jリーグ公式サイトの選手一覧を起点に、選手別のシーズンスタッツを取得します。チーム別ランキングを使うため、移籍した選手も指定チーム在籍時の成績になります。2018年は選手個人ページの詳細データが公開されていないため、チーム別ランキングから取得できる値だけを出力します。CSVの取得方法欄には「公式チーム別ランキングのみ」と記録します。2019年以降は個人ページのデータも使い、チーム別ランキングにない値を補います。ポジションに応じて詳細項目が異なるため、チーム内の誰かに項目があればCSV列に含め、その選手に該当しない項目は空欄にします。J2・J3では公式に提供されていない走行距離・スプリント系の10項目は取得できません。J2/J3でこれらの項目を`--stats`に指定するとエラーになります。`--stats` を省略すると全項目を取得対象にします（J2/J3では非公開項目を除きます）。特定項目だけ取得する場合は、項目コードをカンマ区切りで指定します。

```shell
py main.py --season 2026 --category j1 --team shimizu
py main.py --season 2026 --category j1 --team shimizu --stats game,score,assist
py main.py --season 2026-27 --category j1 --team shimizu
py main.py --season 2026-27 --category j2 --team yokohamafc
```

CSVには対象チームの選手一覧とスタッツを出力します。スタッツは公式ページの表示に合わせてリーグ戦の成績です。2019年以降はチーム別ランキングで値が得られない場合に個人ページの値を使います。2018年はランキングのみを使い、取得に失敗した項目は `-` として失敗ログ `stats_<チーム>_<シーズン>_<カテゴリ>_errors.csv` に記録します。

手作業の補完値は `data/stat_fallbacks.csv` に1行ずつ登録します。`season,category,team,player_id,stat` の組み合わせで対象データを識別し、値・取得方法・根拠URLも記録します。同じキーを複数登録した場合や値が数値でない場合は、誤った補完を避けるため処理を中断します。補完値は公式チーム別ランキングの取得値よりも優先されます。

### 対話式ウィザード（初心者向け）

```shell
py main.py
```

※ 途中で `all` を選ぶと全チーム取得となり、10〜15分程度かかる場合があります。

### 引数指定

```shell
py main.py --season 2026 --category j1 --team shimizu --output output
```

※ 引数なしで実行した場合は対話式ウィザードが起動します。引数ありのときに省略した値は上記のデフォルトが使われます。スタッツ取得は選手一覧起点で行います。

#### チーム一覧を表示

```shell
py main.py --list-teams --season 2025 --category j1
```

#### スタッツ項目コードを表示

`--stats` に指定できるコードと日本語名を確認できます。J2/J3では、取得可能な項目だけを表示します。

```shell
py main.py --list-stats --category j1
py main.py --list-stats --category j2
```

#### 現行Jリーグ一覧にない過去選手を一覧

```shell
py main.py --list-inactive-players --season 2020 --category j1 --team shimizu
```

J1/J2/J3すべての現行選手一覧と照合し、該当選手を `output/players_not_current_<チーム>_<シーズン>_<カテゴリ>.csv` に出力します。`--team all` では、そのシーズン・カテゴリの全チームを対象にします。現行一覧にないことは、引退・海外移籍・JFL所属などを区別するものではありません。

## パラメータ

| 引数 | 説明 | デフォルト値 | 例 |
| :--- | :--- | :---| :--- |
| `--season` | 取得したいシーズン | `2026-27` | `2026` |
| `--category` | カテゴリ（j1 / j2 / j3） |	`j1` | `j2` |
| `--team` | チームの英名（または `all`） | `shimizu` | `kashima`, `urawa` |
| `--output` | 保存先ディレクトリ | `output` | `my_data` |
| `--interactive` | 対話式ウィザードで実行 | なし | - |
| `--list-teams` | チーム一覧を表示して終了 | なし | - |
| `--list-stats` | カテゴリで取得可能なスタッツ項目を表示して終了 | なし | `--list-stats --category j2` |
| `--list-inactive-players` | 現行J1/J2/J3一覧にない過去選手をCSV出力 | なし | `--list-inactive-players --season 2020 --team shimizu` |
| `--stats` | 取得項目（カンマ区切り、省略時は全項目） | 全項目 | `game,score,assist` |

## 出力ファイル

実行後、指定したディレクトリ（デフォルトでは output/）に以下の形式でCSVが生成されます。
    -  stats\_shimizu\_2025\_j1.csv
    - stats\_all\_2025\_j1.csv

## 注意事項

- 本ツールは[Jリーグ公式サイト](https://www.jleague.jp)のHTML構造に依存しています。サイトの変更により動作しなくなる可能性があります。
- サーバーへの負荷を抑えるため、各項目の取得前に短い待機時間（約0.5秒）を設けています。項目が多い（82項目 × 全チーム）場合は、それだけで数分かかります。
- `--team all` 実行時は全チームを巡回するため、10〜15分程度かかる場合があります。
- 通信エラー（タイムアウト、429、5xx）は自動で最大3回リトライします。429 の場合はサーバーの `Retry-After` 指示に従います。
- 2019年以降の取得では、現行J1/J2/J3選手一覧にない選手の個人ページ取得を省略します。ランキングや補完表に値がない項目は未取得（`-`）として記録します。現行一覧との照合には2026-27シーズンの選手一覧を使います。
- 2017年以前は、現行の取得形式で選手一覧・個人スタッツを確認できないため対象外です。2018年はチーム別ランキングのみを使います。

## よくある失敗

- `py`, `python3` コマンドが動かない  
  Pythonがインストールされていない可能性があります。Python 3.12以上を入れてから再実行してください。
- `チーム一覧の取得に失敗しました`  
  ネットワークが不安定な場合に発生します。時間をおいて再実行してください。
- `... ランキング取得失敗 (URL: ...)` と表示されて止まる  
  上記の「重要」節のとおり、サイト側の構造変更が原因の場合があります。
- `--season は4桁の半角数字で指定してください`  
  `--season` には2018〜2026の4桁の半角数字または `2026-27` を指定してください。2017年以前は対象外です。
